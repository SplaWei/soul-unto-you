## 4. P2 延后清单（不阻塞 v0.5，别扩大范围）

- `readJsonlSafe` 的 limit 按行数而非有效对象数；空行/坏行会让返回少于 limit；null/数组行未过滤。

- SSE 无 keepalive；webhook 只存内存；emit 对每个 webhook 直接 fetch，无并发上限。
- `/api/health` 公开却触发全量 countPendingEntries；`/api/archive` 返回全量 episodes/experiences。
- 门禁 3 不做类型检查/不覆盖 adapters；门禁 6 只查 5 个核心文件；5.5d mock 只断言 4 个 case；5.1-C 只测 percept；5.5b 不测伪造 personId。
